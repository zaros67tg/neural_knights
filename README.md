# Neural Knights

A healthcare queue management portal (HTML/CSS/JS) featuring patient and doctor dashboards, live queue tracking, and a problem desk for AI-style symptom triage.

## Files

* `index.html`, `doctor-dashboard.html`, `doctor-login.html`, `doctor-select.html`, `patient-dashboard.html`, `patient-login.html`, `problem-desk.html` - Application pages.
* `auth.js`, `data.js`, `queue.js` - Authentication, data persistence, and queue logic.
* `style.css` - Shared styling.

## Quick Start

Open `index.html` with the VS Code Live Server extension or any local web server.
